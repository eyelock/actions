# Security Policy

These actions run in other people's CI, and some of them gate merges. Report a vulnerability
privately through [GitHub security advisories](https://github.com/eyelock/actions/security/advisories/new),
not as a public issue.

Supported: the latest release of each action's current major version (`<action>-v<major>`).

Vulnerabilities in the tools an action wraps (for example NVIDIA SkillSpector) belong upstream;
tell us too if the action's pin needs to move.
